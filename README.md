## Featured work
| Project | What it is |
|---|---|
| 🚚 **[RoadLink](https://roadlink.co.in)** | Live multi-tenant fleet SaaS for Indian road freight, built solo: **Django 5, PostgreSQL, Redis, Celery, Docker** (~100k lines of Python) and a **Flutter** app (~41k lines of Dart) covering owner, office, plant and driver roles. Handles dispatch, GST-compliant billing, truck ledgers, POD capture and GPS tracking. Its two-model (OpenAI + Gemini) AI ledger reconciliation runs deterministic checks first, cutting a run from **~40 model calls to 1–2**, and every change can be undone in one click. Production Docker image cut from 6.4 GB to 845 MB. |
| 🤖 **Autonomous Trading Floor** | Multi-agent system (analyst, strategy, risk and execution agents) across **6 MCP servers and 44 tools**, with evaluation gates on every proposed action and per-task model choice across Claude, GPT and Gemini. |

| 🔀 **[llm-harness](https://github.com/abhisek11/llm-harness)** | TypeScript harness that routes LLM calls across free tiers (Groq, Gemini, GLM, Cerebras, OpenRouter). |
